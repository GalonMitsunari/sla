Tout savoir sur les Noyaux

Noyau Attaque (DCC)
  • DCC sur Core ATK +20%
  • MP consumption +12%
  • MP recovery +10%
  • 3 basic ATK → +3% jauge ult (cd 10s)
  • Ult → +5% PM
Noyau Défense
  • Break +10%
  • Heal reçu +8%
  • Si HP < 70% → DEF +6% (cd 25s)
  • Dégâts reçus -10%
  • Ult → shield 10% HP
Noyau PV
  • Si PM < 20% → PM +30% (1×/game)
  • Basic skill → shield 10% ATK
  • Si PM < 50% → DEF +6%
  • Si HP < 30% → soin 20%
  • Ult → shield 10% HP

Battle Power
★
Tier minimum Tier 6 – Rang A obligatoire pour toutes vos gemmes
↑
Stats prioritaires ATK% / DEF% / HP% — Aucune stat plate (flat) tolérée
◈
Gemmes PM 8× Baisse coût PM + 8× PM supplémentaire
⊕
Exception BOT Si contenu de prédilection = BOT → All-in Vitesse
◎
Précision (hors BOT) 10× Pénétration de défense + 6× Dégâts critiques
